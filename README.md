# C Programming Practice Repository

## 📌 Overview
This repository contains a comprehensive collection of **C programming practice programs**, created to strengthen fundamentals in **procedural programming**, **logic building**, and **problem solving**.

The programs cover a wide range of topics starting from **basic syntax** to **arrays, strings, functions, pointers, dynamic memory allocation, matrices, and pattern problems**.  
This repository is mainly intended for **students and beginners** learning C programming.

---

## 🧠 Topics Covered

### 🔹 Basics of C
- Input / Output programs
- Arithmetic operations
- Relational & logical operators
- Operator precedence
- Simple interest, area, average calculations

### 🔹 Conditional Statements
- `if`, `if-else`
- Nested `if`
- Switch case programs
- Calculator using switch case

### 🔹 Loops
- `for`, `while`, `do-while`
- Nested loops
- Pattern printing programs
- Factorial programs
- Prime number logic

### 🔹 Arrays
- 1D array operations
- Sum, product, min & max
- Linear search
- Reverse array (multiple approaches)
- Prime numbers in array
- Dynamic Memory Allocation (DMA)

### 🔹 2D Arrays & Matrices
- Matrix addition
- Matrix multiplication
- Matrix transpose
- Sum of rows and diagonals
- Practice problems on matrices

### 🔹 Strings
- String length
- String copy (with & without built-in functions)
- String compare
- Palindrome check
- Reverse string
- ASCII value programs
- Word and character counting

### 🔹 Functions
- Function basics
- Functions with arrays
- Functions with loops and conditions
- Modular programming approach

### 🔹 Pointers
- Swapping using pointers
- Sum of array using pointers
- Call by reference programs

### 🔹 Number System & Logic Programs
- Binary to decimal conversion
- Decimal to any radix
- One radix to another radix
- Reverse of number
- Sum of digits

### 🔹 Competitive Programming Practice
- CodeChef problems
- LeetCode-based logic programs
- Smart interview problems

---

- Each `.c` file represents **one independent program**
- File names clearly indicate the **problem statement**
- Programs are written in **simple and readable format**
- Suitable for **college labs, practice, and interviews**
